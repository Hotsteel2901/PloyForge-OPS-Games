# 更新日志

## v2.0.1 — Reloaded（移动端与设置修复）

### 修复
- **移动端按钮全部无法点击**：
  - 触控层与菜单层此前同处一层 CanvasLayer，现按层级显式分层
    （HUD 10 / 触控 20 / 暂停·购买 30 / 计分 32 / 主菜单 34 / 联机 36 / 设置 40）；
  - 关闭 `emulate_mouse_from_touch`，触屏设备忽略模拟鼠标事件，
    触控状态不再被鼠标事件打回；
  - `InputHandler` 键盘层与触屏层分离并 OR 合并，互不覆盖。
- **Android 显示异常**：启用 `stretch/mode=canvas_items` + `aspect=expand`，
  移动端 UI 基准 ×1.35 缩放（`Platform.apply_ui_scale`），触控布局按安全区兜底、
  随窗口 `resized` 重排；主菜单整页可滚动。
- **修复地图卡片"已选"角标错位**（锚点重置 position 的问题）与"选择地图"标题未居中。

### 改进
- **设置中心重做**：新 `SettingsPanel` 由 `Settings.SCHEMA` 驱动自动生成，
  六类共 56 项（画面 19 / 声音 7 / 操作 13 / 玩法 8 / 联机 5 / 辅助 4），改动即时生效。
- **原先只存在于配置中、实际无效果的 28 项全部接线**：后处理（色散/模糊/颗粒/亮度）、
  血液/弹壳/弹痕开关、准星样式与颜色、伤害数字、命中音效、视角晃动、屏幕震动、
  色盲模式、大字号、自动换弹、开镜/冲刺切换、陀螺仪、辅助瞄准、失焦静音、
  动态音乐、3D 音效定位（HRTF）、P2P 优先、延迟上限提醒、字幕开关等。
- 新增 `PostFX` 全屏后处理层（layer 6，UI 不受影响），全部关闭时零开销。
- 新增对局强度驱动的动态 BGM 变调、失焦自动静音、开镜灵敏度倍率。

## v2.0.0 — Reloaded

### 新增
- **八种游戏模式**：拆弹、团队死斗、自由混战、军备竞赛、占点、夺旗、生化、生存波次
  全部通过 `ModeBase` 解耦，模组可注册新模式。
- **联机对战**：局域网直连（内置 WebSocket 服务端 + UDP 发现）、公网中继（Node.js 零依赖）、
  专用服务器；房主权威 + 客户端预测 + 远端插值 + 回溯命中。
- **Android 版**：虚拟摇杆 / 拖拽视角 / 11 个可布局按键 / 陀螺仪 / 安全区 / 返回键处理。
- **模组系统**：`mod.json` + JSON 武器 + 极简地图描述 + GDScript 模式；
  `tools/modc` 提供脚手架、校验、打包（`.pfmod`）、监听、安装。
- **武器扩至 32 把**：新增左轮、机关手枪、PDW、AK、DMR、双管霰弹、转管机枪、磁轨炮、
  电击枪、战术弩，以及闪光/烟雾/燃烧/诱饵四种投掷物。
- **配件系统**：瞄具、枪口、握把、弹匣、枪托，14 种配件带真实数值修正。
- **感知型 Bot AI**：视锥 + 听觉 + 记忆 + 效用决策 + 二叉堆 A\* + 人类化瞄准 + 5 档难度。
- **设置中心**：45+ 项，分六类，支持导入导出与旧版迁移。
- **性能系统**：画质自动分档、自适应 3D 分辨率、帧时间监控（F3）。

### 改进
- 命中判定：新增护甲穿透、墙体穿透、按移动/连发的动态散布、近战爆头。
- 投掷物：抛物线 + 弹跳 + 地面摩擦 + 按类型区分效果，爆炸不穿墙。
- 后坐力现在会真实抬高准心（原先只影响视觉）。
- Bot 寻路从 O(n²) 线性扫描改为二叉堆 A\*，4000 节点场景寻路耗时下降约 90%。
- HUD 新增闪光致盲、屏幕震动、模式化比分显示。
- 主菜单模式按钮改为网格自适应，避免窄屏溢出。

### 修复
- 修复服务端在 headless/无交换链环境下设置 VSYNC 导致主循环阻塞。
- 修复换弹时弹药比例错误、弹匣配件可刷子弹。
- 修复友伤判定在 FFA 模式下误伤队友（现在按模式决定）。
- 修复模式附加数据（据点/旗帜）在 Bot 侧被当作字符串访问导致每帧报错。
- 修复军备竞赛回合计时器从未启动、回合无法结束。
- 修复 `_st()` 状态访问在联机客户端下返回空导致 HUD 全空。

### 兼容性
- 需要 Godot **4.7.2**（v1 为 4.7.1）。
- 旧 `settings.cfg` 会自动迁移到 `settings_v2.cfg`。
- Mod API 版本 `2`（v1 无 Mod 系统）。
