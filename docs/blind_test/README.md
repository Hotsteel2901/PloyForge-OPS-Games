# 盲测对比：PolyForge: Ops vs Counter-Strike 2

本目录用于"盲测"——你（评审者）在不知道哪张是哪张的情况下，凭肉眼判断哪款游戏的画面更优。

## 素材

- `cs2_ref/` — 8 张 CS:2（Valve 官方商店图，1920x1080）
- `ours/` — 20 张 PolyForge: Ops（自渲染 1920x1080：3 张地图的 17 张场景图 + 3 张实时对局截图）

## 测试流程

1. 打开两个目录，用系统看图工具**并排**浏览。
2. 每张图按 5 项打分（1-5）：光照氛围 / 材质质感 / 场景复杂度 / 色彩平衡 / 画面锐度。
3. 汇总：哪一项、哪张图让你能一眼分辨出"这是 CS:2 / 这不是 CS:2"？
4. 结论判定标准：
   - 若「ours 平均分 ≥ cs2 平均分」→ 视觉品质达标（3A 水准）
   - 若「ours 平均分接近（差距 < 0.5 分）」→ 达到同水准
   - 若差距明显 → 需要继续迭代

## 技术栈（供参考，不计分）

- Godot 4.7.1 Forward+，d3d12，外部 CC0 素材（ambientCG 2K PBR / Poly Haven HDRI / 10 把 GLB 枪械）+ 程序化资源兜底
- SDFGI 体素 GI（4 级联）、SSR、SSAO、体积雾、ACES 色调映射、TAA、HDRI 全景天空
- 2560x1440 渲染，1920x1080 输出；30Hz 模拟 + 渲染插值，对局 87-98 FPS
- 19+ 把武器、开放 140x140 沙漠小镇、全部实心道具带碰撞
