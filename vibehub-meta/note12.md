Web 端性能与音频修复：
- 修复 project.godot 里历史遗留的“伪注释”键：Godot 的配置文件只认 `;` 开头注释，之前用 `#` 写的说明整行被并进了设置名，导致 Web 特化优化实际从未生效
  - 阳光阴影图集 4096→2048、软阴影 Soft High→Soft Very Low、位置光阴影图集 4096→2048、关闭各向异性过滤、关闭 2D MSAA（GLES3 本就不支持，之前还会刷警告）
  - 渲染方式写成了错误的键名 rendering_method.web，已修正为 renderer/rendering_method.web（Web 用 GL Compatibility）
- Web 音频链路重做，解决“音乐与音效不发声/消失”：
  - BGM（174 秒 OGG）改为 Stream 播放：Sample 模式每次播放要把整首歌解码成 PCM（约 66MB/首）并同步阻塞主线程，多首之后内存持续累积，是低配设备上音频失效、页面卡死的主要风险
  - 音效统一走 Sample 并在启动时预注册到 Web Audio：开枪/脚步不再参与引擎逐帧混音，掉帧不会吞掉音效，首次播放也不再卡顿
  - Web 输出缓冲 50ms→150ms，给主线程抖动留余量，减少音乐断续
- 新增 Web 自适应 3D 分辨率（0.50~0.85）：按实际帧率自动升降，低配设备优先保帧率，UI 始终原生清晰
- 主音量为 0% 时开局给出明确提示，避免被误判成“音频坏了”
- 新增 F8 调试叠层：帧率、内存、音频播放模式、实际输出电平（RMS），便于后续排查
- 导出体积：剔除 Preview.png、Unity/Unreal 安装示意图等未使用资源，Web 包体减少约 2MB
